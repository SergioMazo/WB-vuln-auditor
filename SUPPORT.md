# Support

WB Vulnerability Auditor is an experimental community project. It provides no
service-level or response-time guarantee.

Use:

- a bug report for reproducible defects;
- a documentation issue for unclear or incorrect instructions;
- a feature request for a narrow defensive improvement.

Include the Python version, operating system, sanitized output, and the exact
offline test command. Never post API keys, real targets, generated CSV files,
client data, credentials, or unredacted request errors.

Questions about a private security weakness must follow
[SECURITY.md](SECURITY.md).
